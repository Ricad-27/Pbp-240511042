# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, Java, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Umumnya menggunakan client-server, dengan frontend di browser dan backend di server | Umumnya berjalan secara lokal pada sistem operasi, dapat terhubung ke server | Berjalan pada sistem operasi perangkat mobile dan dapat menggunakan layanan server |
| Cara distribusi | Diakses melalui browser menggunakan URL | Diunduh dari website resmi, toko aplikasi, atau dipasang melalui installer | Didistribusikan melalui toko aplikasi seperti Google Play Store dan Apple App Store |
| Keunggulan | Mudah diakses tanpa instalasi khusus, lintas platform, dan pembaruan dapat dilakukan di server | Dapat memanfaatkan sumber daya komputer secara langsung dan mendukung integrasi dengan sistem operasi | Portabel, mendukung layar sentuh, dan dapat memanfaatkan fitur perangkat seperti kamera, GPS, serta sensor |
| Keterbatasan | Bergantung pada browser dan sering membutuhkan koneksi internet untuk layanan online | Instalasi dan kompatibilitas dapat berbeda antar sistem operasi; pembaruan perlu dikelola | Memiliki keterbatasan baterai, ukuran layar, memori, dan kompatibilitas perangkat |
| Contoh aplikasi | Google Docs versi web, Gmail versi web | Visual Studio Code, Microsoft Word versi desktop | WhatsApp Android, Google Maps pada smartphone |

## 3. Refleksi
